# Vnstock Vibe Coding Agents Context

Dưới đây là cấu hình các AI Agent chuyên biệt cho phân tích dữ liệu thị trường chứng khoán Việt Nam:

## 1. Technical Analysis Agent (Agent Kỹ Thuật)
- **Nhiệm vụ**: Phân tích đồ thị nến, chỉ báo xu hướng (MA, EMA), động lượng (RSI, MACD), và dải Bollinger Bands.
- **Đầu ra**: Tín hiệu MUA / BÁN / THEO DÕI ngắn hạn và trung hạn.

## 2. Fundamental Agent (Agent Cơ Bản)
- **Nhiệm vụ**: Đánh giá sức khỏe tài chính, các chỉ số P/E, P/B, ROE, biên lợi nhuận và hồ sơ doanh nghiệp.
- **Đầu ra**: Định giá cổ phiếu và đánh giá tiềm năng tăng trưởng dài hạn.

## 3. Risk Management Agent (Agent Quản Trị Rủi Ro)
- **Nhiệm vụ**: Đo lường độ biến động (Volatility), mức sụt giảm tối đa (Max Drawdown), đề xuất ngưỡng Cắt lỗ (Stop-loss) và Chốt lời (Take-profit).
- **Đầu ra**: Báo cáo đánh giá rủi ro danh mục và khuyến nghị tỷ trọng vốn.

## 4. Master Strategy Agent (Agent Tổng Hợp Chiến Lược)
- **Nhiệm vụ**: Tổng hợp kết quả từ 3 Agent trên, giải quyết mâu thuẫn tín hiệu và đưa ra quyết định giao dịch cuối cùng.
